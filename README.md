# HaxNex

**Un cliente de escritorio nativo para HaxBall.**

HaxNex es un proyecto que busca ofrecer una experiencia de escritorio para HaxBall, con una interfaz nativa, herramientas de juego y funciones sociales integradas.

> **Estado del proyecto:** versión inicial `0.1.3`. El desarrollo continúa y algunas funciones pueden estar incompletas o pendientes de validación.

## Características

- **Cliente de escritorio nativo:** una experiencia diseñada para ejecutarse como aplicación de escritorio.
- **Interfaz de juego:** acceso a las funciones principales del cliente desde una interfaz integrada.
- **Entrenamiento:** herramientas para practicar y mejorar las habilidades de juego.
- **Herramientas de partido:** funciones orientadas a mejorar la experiencia durante las partidas.
- **Repeticiones y estadísticas:** herramientas para consultar y revisar información de las partidas, según la disponibilidad de cada función.
- **Funciones sociales:** integración de funciones relacionadas con perfiles, amigos y salas.
- **Desarrollo continuo:** mejoras de rendimiento, estabilidad y experiencia de usuario.

La disponibilidad de cada característica depende de la versión y de su estado de implementación.

## Descarga

Puedes consultar las versiones publicadas y descargar los paquetes disponibles desde GitHub Releases.

Para utilizar la aplicación, descarga el paquete correspondiente a tu sistema operativo y sigue las instrucciones incluidas en la publicación.

### Windows

La versión inicial está orientada a Windows de 64 bits.

1. Abre la página de [Releases](https://github.com/GonzaloH12/HaxNex/releases).
2. Descarga el paquete de la versión que quieras utilizar.
3. Ejecuta la aplicación siguiendo las instrucciones de esa versión.

**Importante:** conserva juntos los archivos incluidos en el paquete. Algunos componentes auxiliares pueden ser necesarios para determinadas funciones.

## Seguridad

La seguridad y la estabilidad forman parte del desarrollo de HaxNex.

Si encuentras un problema de seguridad, evita publicar credenciales, secretos o datos personales en una incidencia pública. Describe el problema sin incluir información sensible y utiliza un canal privado de contacto cuando esté disponible.
